# Operation Glassbox — Seven-Step Hacking Methodology Lab

A dependency-free animated browser lab covering reconnaissance, scanning, enumeration, vulnerability analysis, gaining access, maintaining access, and clearing tracks at a conceptual level.

## GitHub Pages files

- `index.html`
- `styles.css`
- `app.js`

Keep the three files together. No package installation or build process is required.

## Instructor file

- `INSTRUCTOR-ANSWER-KEY.txt`

The answer key contains every answer, teaching explanation, facilitation prompt, and completion standard. Keep this file out of the student-facing GitHub Pages upload if solutions should remain private.
